# dsh-exv-parallax-bg

DSH EXV Theme 的背景层：分层视差背景、代码雨与扫描波、15 个 Live2D 主人物（入场 / 待机 / 眼神跟随）。

属于 [DSH EXV Theme](https://github.com/VMWHW/dsh-exv-theme) 主题包，不要单独安装；安装入口是：

```bash
dsh plugin --profile desktop add dsh-exv-theme
```

或在 DSH 侧边栏 **Plugins → Add plugin** 里填 `dsh-exv-theme`。

本包内嵌 Live2D Cubism Core、pixi.js、pixi-live2d-cubism4，以及《少女前线》的模型素材；它们不在 MIT 范围内，详见主题包根目录的 THIRD_PARTY_NOTICES.md。
